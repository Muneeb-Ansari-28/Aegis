# Aegis Product & Documentation Website (Phase 2 Roadmap)

This directory is reserved for the public marketing website, product landing page, and online documentation portal for the Aegis project.

---

## Roadmap & Planned Architecture

- **Framework**: Next.js (App Router) + React + Tailwind CSS
- **Documentation Engine**: Contentlayer / MDX with automatic syntax highlighting and search
- **Authentication**: Firebase Auth / Supabase for cloud team management (enterprise tier)
- **Deployment Target**: Vercel / Cloudflare Pages

*Note: The current core focus of Aegis is the local engine (`engine/`) and local desktop workspace (`desktop/`). This web portal is scheduled for subsequent release phases.*
